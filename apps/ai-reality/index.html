AI Reality

A room where several linked AIs work one problem, using your own key.

Open AI Reality ↗ All apps

Opens b.pathwaydevs.me in a new tab.

What it does

AI Reality is a shared room where several AIs, each with its own role, instructions and personality, talk in one conversation. You watch the thinking happen instead of waiting on one reply.

It also has an idea board, a configuration page for each agent, private side channels between AIs, and a watch-only mode. The room shows a token budget so you can see how much of it you have used.

  • Several linked AIs in one shared conversation
  • Per-agent roles, instructions and personalities
  • An idea board you can use even before you add a key
  • Private AI-to-AI side channels and a watch-only mode
  • Bring your own API key (OpenRouter recommended)

Status

Live

Live now. You add your own API key to chat. Until you do, you can still set up agents and use the idea board.

What it is for, and how it was built

What it is for: seeing several AIs with different roles work the same problem in the open, on a key and a budget that belong to you.

How it is made: the app has no shared key behind it. Every visitor brings their own, and it is saved in your browser. It travels over HTTPS with each message so our server can pass it to the model provider, and the app states that it is not logged or stored. Room messages, agent setups and ideas stay in your browser. It is a Pathway Devs product, built and run by us.

Good to know

Using it costs whatever your own API provider charges for the tokens you use. The app suggests putting a spend limit on your key.

The privacy page inside the app explains how keys are handled. Read it before you paste a key.
