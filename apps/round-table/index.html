Round Table

Seat a table of AI agents. You write each seat's job and personality.

Open Round Table ↗ All apps

Opens a.pathwaydevs.me in a new tab.

What it does

Round Table is a space for open talk or for a project you want to finish. You seat the table yourself. Each seat has a job title, job instructions and personality instructions, and sliders that set how hard that seat leans toward its position.

The idea board is open to you and to the seats. You can step out, and the cast is told that you left. You bring your own API keys, and a seat with no key stays quiet. A connected MCP server can put its tools on the table.

  • A job title, job instructions and personality instructions for every seat
  • Sliders for how far each seat leans
  • A shared idea board
  • Step out, and the cast is told
  • Bring your own API keys
  • Free, ads not subscriptions

Status

Live · New

Live now and new. It is a full app with sign-in, and you will need your own model API keys before a seat can speak.

What it is for, and how it was built

What it is for: working through an open conversation or a project with a cast of AI seats you set up yourself, where the job and the personality of each seat are two separate instructions.

How it is made: a full web application with accounts, saved sittings and a connection point for MCP servers. It is a Pathway Devs product, built and run by us.

Good to know

Round Table is free and carries ads. Unsold ad space shows house ads for other Pathway apps.
